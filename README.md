# QRクイズ

GitHub Pages だけで動く、QRコード参加型の早押し4択クイズです。
司会者のブラウザがゲームサーバー役となり、参加者のスマホと WebRTC（PeerJS）で直接通信します。サーバー契約やアカウント登録は不要です。

## できること

* QRコードを読み取るだけで参加（25人程度の同時プレイを想定）
* 回答スピードに応じた得点（正解時 1000pt から 500pt まで時間に比例して減少）
* 各問題ごとに「トップ正解者」と2位以降の最速正解者を表示
* 各問題終了時点の順位表（順位の上下、獲得点数つき）
* 最終結果の表彰台表示と CSV 保存
* 参加者のスマホがスリープしても自動で再接続し、得点を引き継ぎ

## 公開手順（5分程度）

1. GitHub で新しいリポジトリを作成します（Public を推奨。Private の場合は有料プランが必要です）
2. このフォルダ内のファイルをすべてアップロードします（Add file → Upload files）
3. Settings → Pages を開き、Source を「Deploy from a branch」、Branch を「main」「/(root)」にして Save
4. 1〜2分後に表示される URL（例 `https://ユーザー名.github.io/リポジトリ名/`）が司会者画面です

## 当日の使い方

1. 司会者 PC で上記 URL を開き「ルームを作成」を押してプロジェクターに映します
2. 参加者はスマホで QR コードを読み取り、ニックネームを入力して参加します
3. 全員がそろったら「ゲーム開始」を押します
4. 以降は Space キー（またはボタン）で「出題 → 正解発表とトップ正解者 → 現在の順位 → 次の問題」と進行します
5. 全員が回答した時点で自動的に締め切られます

注意：司会者画面を再読み込みしたり閉じたりすると、ゲームの状態が失われます。

## 問題の編集

`questions.json` を GitHub 上で直接編集します（鉛筆アイコン → Commit changes）。

```json
{
  "title": "クイズのタイトル",
  "defaultTime": 20,
  "questions": [
    {
      "text": "問題文",
      "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "answer": 2,
      "time": 15
    }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `answer` | 正解の番号（1から数えます） |
| `choices` | 2〜4個 |
| `time` | その問題の制限時間（秒）。省略時は `defaultTime` |

司会者画面の「別の問題ファイル（JSON）を読み込む」から、手元の JSON をその場で読み込むこともできます。

## 得点ルール

`得点 = 1000 − 500 × (回答時間 ÷ 制限時間)`（正解時のみ。不正解と未回答は0点）

同点の場合は、正解した問題の合計回答時間が短い人を上位とします。
定数は `host.js` 冒頭の `SCORE_MAX` と `SCORE_MIN` で変更できます。

## 接続できない場合

* 社内 Wi‑Fi や VPN が WebRTC 通信を遮断している可能性があります。司会者 PC をテザリングや来客用 Wi‑Fi に接続すると改善する場合があります
* 参加者はスマホのモバイル回線のままで参加できます
* 事前に2〜3台で接続テストを行うことをお勧めします

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `host.js` | 司会者画面（プロジェクター用） |
| `play.html` / `player.js` | 参加者画面（スマホ用） |
| `style.css` | 共通デザイン |
| `questions.json` | 問題データ |
